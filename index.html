为什么你无法使用？（使用必读）

我将用最直白、最不绕弯子、最接地气的方法告诉你，为什么你无法使用：
① 未授予「悬浮窗」权限。桌宠的本质是显示在其他应用之上，所以需要授予此权限。
② 由于代码问题，它未显示 API 地址，所以用户需要自己填写 API 地址如下——但它并不是 API Key：https://api.deepseek.com
③ 建议授予「自启动」权限或「无视电池消耗」之类的权限，防止被杀后台。授予此权限之后，在后台界面删除之后，应用可以在 30 秒内启动，这样你在后台就看不到这个界面了。
④ 做网页时打错字了，将 DeepSeek 娘改成了千问娘。千问娘目前仍然在制作中，制作过程中出现了大量 bug，所以任何下载 v1.0 的用户在出现问题后立即卸载，下载其它版本的。
⑤ v2.6 以后，基本就不需要卸载重装了，只需下载最新版本 OTA 即可。
